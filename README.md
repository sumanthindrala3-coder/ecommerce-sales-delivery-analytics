🛒 E-Commerce Sales & Delivery Analytics

📌 Project Overview
This project analyzes e-commerce sales performance, delivery efficiency, and customer behavior using the Olist Brazilian E-Commerce dataset.

The goal is to generate actionable insights to improve revenue, optimize delivery operations, and enhance customer satisfaction.


 🎯 Objectives
- Analyze revenue and order trends
- Evaluate delivery performance and delays
- Identify top-performing states and categories
- Understand customer order behavior


 🛠️ Tools & Technologies
- Power BI (Dashboard & Visualization)
- SQL (Data Analysis)
- Python (Data Cleaning)
- Excel (Preprocessing)

 📂 Project Structure

- **Dashboard/** → Dashboard screenshots
- **Data/** → Dataset files
- **SQL/** → SQL queries
- **notebooks/** → Python analysis



🔍 Key Insights

- 📈 Revenue shows consistent growth with seasonal spikes
- 🚚 Late deliveries (~16%) impact customer satisfaction
- 🛍️ Top categories drive a major portion of revenue
- 🌍 Southeast region contributes highest revenue



💡 Business Recommendations

- Improve delivery efficiency in high-delay regions
- Focus on high-performing product categories
- Reduce late deliveries to improve retention
- Optimize logistics for faster order fulfillment


 🚀 Skills Demonstrated

- Data Visualization (Power BI)
- SQL Analysis
- Data Cleaning (Python)
- Business Insight Generation
- Dashboard Design
